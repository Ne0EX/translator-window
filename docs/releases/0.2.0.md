# Translumo Local 0.2.0

Candidate date: 2026-09-26

Translumo Local 0.2.0 focuses on readable Thai caption layout and color-page presentation. The source tree carries version 0.2.0 for development. The reader's reference-page typography and stylized-text completeness remain unfinished; existing color cues and fallback do not meet that target. The immutable tag and source archive remain unpublished until implementation and exact-candidate acceptance are complete.

This release keeps OCR and translation local. Translation APIs are tracked separately in issues #14–#18 and are not implemented here.

## Highlights

- Separates recognized text bounds, padded source covers and caption placement anchors. Changing cover padding no longer moves an otherwise unchanged caption.
- Bounds local captions to an explicit area around their source and bounds numbered margins to the selected capture target. Thai overwrite captions retain a 12-DIP reading floor; an impossible fit leaves the source visible and reports the existing placement failure.
- Chooses font size, width, wrapping and position together, while preserving complete Thai words, grapheme clusters, punctuation and numbers.
- Reuses stable caption geometry by value across equivalent frames and skips a final repaint when both caption semantics and the pixels beneath the current layer are unchanged.
- Qualifies narrow CPU-only reconstruction for plain color fills and smooth linear gradients. It paints only the inferred lettering footprint and uses a transparent caption background. Tested nonlinear patterns and large or compact interior components fail the bounded qualifier and fall back to visible source plus a readable caption.
- Adds automatic emphasis for obvious wide headings plus dialogue, narration and emphasis overrides with Thai typeface, weight, foreground and outline/shadow controls. Existing settings load with the dialogue defaults.
- Adds deterministic synthetic fixed-text replay and an opt-in local full-pipeline replay. Private reader images remain ignored and are never added to release assets.

## Supported presentation matrix

The 2026-09-27 local candidate adds Auto heading treatment for qualified bright
lettering on red bands: sampled gradients, a solid glyph stroke/glow, local Thai
fitting and pixel-checked cover reuse. Explicit typeface/color/effect controls
remain available. Three fixed headings on the reader's reference now render
locally; this does not resolve the actual-page OCR losses or qualify the visible
cover seams. General texture/font imitation and full reference acceptance remain
unfinished. [Evidence and limits](../feedback/2026-09-27-style-target.md).

| Source class | v0.2.0 behavior | Qualification boundary |
| --- | --- | --- |
| Ordinary desktop text | Existing overlay and overwrite modes | Windows OCR/Tesseract path; manga container rules do not apply |
| Monochrome manga dialogue | Local overwrite with complete Thai text and readable fallback | Qualified by synthetic geometry, wrapping and lifecycle checks |
| Dense charts | Local placement where readable; numbered in-frame margins when required | Thin ruled family charts only; general diagrams remain unsupported |
| Plain colored balloon or banner | Source-text footprint reconstruction and transparently backed Thai caption | Stable color around the lettering and a permitted local area are required |
| Smooth color gradient | Bounded gradient reconstruction and transparently backed Thai caption | Linear local gradients only; fixture pixels outside the source-text footprint must remain unchanged |
| Detailed artwork behind lettering | Inputs rejected by the bounded qualifier keep the source visible and use a safe local or margin fallback | Tested patterns/components only; no arbitrary inpainting, face/hair reconstruction or general color-page guarantee |
| Stylized source lettering | Replayed as a separate detection/recognition completeness class | No general detector improvement is claimed without a redistribution-safe failing original |

The generated ChatGPT reference supplied during planning remains a visual direction. It is not a translation oracle and is not produced by the runtime.

## Settings migration

The existing `%LOCALAPPDATA%\TranslumoLocal\settings.json` file remains valid. Missing v0.2.0 caption-style fields default to Dialogue, Leelawadee UI when installed, normal weight, black foreground and outline. A fresh profile starts in Auto, which emphasizes only an obvious wide heading; choosing Dialogue, Narration or Emphasis disables that automatic role choice. Unsupported saved fonts fall back to an installed Thai-capable system font. No font is newly bundled.

## Known limits

- The local translator still makes meaning, name, relationship and short-fragment errors. Layout quality does not establish human translation quality.
- v0.1.0 was reported smoother and less flickery than an intermediate build. One redundant stable-layer repaint is removed in this candidate; the full candidate still needs the matched live comparison requested by `PROB-014`.
- Detailed artwork reconstruction, arbitrary stylized lettering and general color-page translation are unsupported.
- Automatic role selection is deliberately narrow: only an obvious wide heading receives emphasis. Narration and less regular display text need an explicit preset.
- Dense pages can still exhaust every readable local and margin placement. The source remains visible when that happens.
- CPU/GPU warmup, VRAM pressure and native reader animation performance remain hardware dependent. Performance optimization follows feature-complete reader review by `DEC-015`.
- Clean-machine installation and physical mixed-DPI coverage are not claimed by this candidate.

## Release assets

The eventual source archive will exclude downloaded models, virtual environments, private screenshots, local replay manifests and generated diagnostics. It will be created from the final annotated tag and accompanied by a SHA-256 checksum. Published v0.1.0 assets remain unchanged.
